# gako.app

The website for [Gako](https://github.com/gako-app/gako), served by GitHub Pages from this
repository's `main` branch at [gako.app](https://gako.app).

One static page (`index.html`, with its styles inline and no scripts), the icons, and `assets/`:
the screenshot in two sizes and the image link previews show. To preview it locally:

```bash
python3 -m http.server 8090
```
